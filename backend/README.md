# Backend

Hoje o site é estático e não tem backend de fato. O formulário de contato (`frontend/contato.html`) monta um link e redireciona pro WhatsApp via JS client-side — não há servidor, API ou banco de dados envolvidos.

Quando isso mudar (ex: captura de lead numa planilha/CRM, envio de e-mail, API de nota fiscal), o código fica aqui.
